# AGENTS.md — korabeland.com

Stack-specific rules for the korabeland.com codebase. Orchestration mechanics, escalation policy, skill routing, and the three-strike rule live in `../Dev Team/AGENTS.md` and `../Dev Team/VISION.md` — they are not duplicated here.

`CLAUDE.md` at the repo root is a symlink to this file. Edit only `AGENTS.md`.

---

## 1. Stack

- **Astro 6** (TypeScript strict mode) — page routing, SSR via Vercel adapter
- **Tailwind CSS 4** — Vite plugin (`@tailwindcss/vite`), CSS-first config (`@import "tailwindcss"` in `src/styles/global.css`)
- **shadcn/ui** — React islands via `@astrojs/react`; components in `src/components/`
- **Keystatic** — local-git-backed CMS (`@keystatic/core` + `@keystatic/astro`). Content at `src/content/posts/*/`. Admin UI at `/keystatic`.
- **MDX** — `@astrojs/mdx` alongside Keystatic's markdoc format
- **Vercel** — `@astrojs/vercel@10` adapter, `output: 'server'`

**Directory layout:**
```
src/
  pages/         — Astro routes
  components/    — React/Astro components (barrel: src/components/index.ts, auto-generated)
  content/posts/ — Keystatic-managed blog posts (one subdirectory per post)
  layouts/       — BaseLayout.astro
  lib/           — Shared utilities (cn helper, etc.)
  styles/        — global.css (Tailwind entry point)
keystatic.config.ts   — Keystatic collection/schema definitions
astro.config.mjs      — Framework + integration config
```

**Locked decisions:** Keystatic collection path uses trailing slash (`'src/content/posts/*/'`) for index-mode `index.mdoc` resolution. `@keystatic/astro@5` declares peer dep `astro@"2||3||4||5"` but works with Astro 6. TypeScript pinned to `^5` — ecosystem not yet ready for TS6.

## 2. Build & verify

- `pnpm dev` — local dev server
- `pnpm build` — production build (runs the `gen-trail-register.ts` prebuild hook)
- `pnpm verify` — Biome + `tsc --noEmit`
- `pnpm test` — Vitest (non-visual, non-E2E)
- `pnpm test:visual` — Playwright visual + E2E
- `pnpm audit` — Lighthouse CI + axe-core
- `pnpm verify:all` — chains all four; must pass before any PR reaches Korab

## 3. File Ownership Rules

**The most important guardrail in the repo.** The paths below are **ORCHESTRATOR-ONLY**. Parallel subagents MUST NOT create, edit, move, or delete them. Changes flow through the orchestrator as a single commit so two agents never race on the same config.

ORCHESTRATOR-ONLY paths:

- `astro.config.*` and `next.config.*` (any extension — `.mjs`, `.ts`, `.js`, `.cjs`)
- `package.json`
- `pnpm-lock.yaml`
- `tailwind.config.*` (any extension)
- `postcss.config.*` (any extension)
- `tsconfig.json` (and any `tsconfig.*.json` variant)
- `keystatic.config.ts`
- `.env*` — all environment files (`.env`, `.env.local`, `.env.production`, `.env.example`, etc.)
- `.nvmrc`
- `.tool-versions`
- Any `index.ts` / `index.tsx` barrel file (see §4 — auto-generated)
- Everything inside `.claude/` (settings, commands, subagent definitions, hooks)
- `scripts/gen-trail-register.ts` — prebuild hook that writes `src/content/trail-register/commits.json` from `git log`
- `src/content/trail-register/commits.seed.json` — committed fallback data for shallow-clone Vercel builds (the generated `commits.json` is gitignored)

If a subagent needs a change to one of these, surface the request to the orchestrator instead of editing directly.

---

## 4. Auto-generated files

Do not hand-edit. Changes will be silently overwritten on the next generation pass.

- `src/**/index.ts` and `src/**/index.tsx` — barrel files regenerated by `scripts/gen-barrels.ts`

To change what a barrel exports, edit the source files inside its folder and re-run the generator.

---

## 5. Parallel-safe directories

Subagents may create, edit, and delete files freely inside these directories, provided they respect the single-owner-per-subfolder convention:

- `src/components/<new-component>/` — one subfolder per component. An agent owns the whole subfolder (component file, styles, tests, stories).
- `src/content/` — MDX/Markdown content and collection entries.
- `tests/` — Vitest unit tests, Playwright specs, visual regression baselines, fixtures.
- `docs/` — design plans, ADRs, internal notes.

Two agents writing into the same subfolder concurrently will produce merge conflicts. Route concurrent work to distinct subfolders or serialize the tasks.

Any file not listed in §3–§5 is orchestrator-owned by default. Ask first.

## 6. Memory scope

Memory captured from a `korabeland.com/` session should describe stack quirks (Astro, Keystatic, Tailwind, Vercel adapter, shadcn islands) and component decisions. Orchestration and model-tuning lessons belong in Dev Team memory — capture those from a session started in `Dev Team/`. See `../.claude/rules/memory-scope.md` for the full rule.
